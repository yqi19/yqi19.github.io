# yqi19.github.io

Personal academic homepage of Yu Qi (祁煜). Plain HTML, hosted on GitHub Pages.

## Edit
Everything is in `index.html`. Search for `TODO` to find the spots to fill in
(photo, email, bio sentence, paper links). Drop your photo at `assets/avatar.jpg`.

## Preview locally
Just open `index.html` in a browser, or run:
    python3 -m http.server 8000
then visit http://localhost:8000

Publication thumbnails go here. Each file matches the name used in index.html.
Use an animated .gif (loops automatically, like a small video) OR a static .png/.jpg.
Recommended size: ~344x208 (or any 1.65:1 image). If a file is missing, the page
just shows a colored box with the venue name — nothing breaks.

Expected filenames:
  scaleup.gif       Scale Up Strategically
  pix2act.gif       Pix2Act
  actionmap.gif     Action Map Policy
  mmecofpro.gif     MME-CoF-Pro
  equact.gif        EquAct
  mmecof.gif        Are Video Models Ready / MME-CoF
  bear.gif          BEAR
  residual.gif      Residual Rotation Correction
  hierskill.gif     Generalizable Hierarchical Skill Learning
  mmecot.gif        MME-CoT
  twobytwo.gif      Two by Two
  thinkgrasp.gif    ThinkGrasp
  pattern4ego.gif   Pattern4Ego

Tip: to use a real video file instead of a gif, replace the <img> tag for that
paper in index.html with:
  <video src="assets/pubs/NAME.mp4" autoplay muted loop playsinline></video>
